# Лекторий — семантический поиск по видеолекциям

Мультиязычное веб-приложение для загрузки MP4/WebM и видео по ссылкам с платформ, поддерживаемых yt-dlp. Лекторий извлекает аудио, распознаёт речь локальными моделями, строит мультиязычный семантический индекс, показывает совпадения с таймкодами, синхронный транскрипт, краткий пересказ и тематические главы.

## Версия для жюри

Автономная демонстрация находится в `outputs/lectorium-jury/`; откройте `index.html` на компьютере без интернета. Готовая инструкция для самостоятельной проверки членами жюри и описание каждой доступной функции приведены в `outputs/lectorium-jury/README_ЖЮРИ.md`. Архив для передачи — `outputs/lectorium-jury.zip`. Демонстрационные данные включены в комплект; настоящая загрузка, распознавание и вход работают в основной версии на `https://demoground.ru`.

## Возможности

- загрузка MP4 и WebM (до 500 МБ) или импорт по ссылкам поддерживаемых yt-dlp видеоплатформ, включая YouTube, VK Видео и Rutube;
- выбор максимального разрешения при импорте по ссылке; загрузчик выбирает лучший доступный формат не выше выбранного и объединяет дорожки при необходимости;
- сворачиваемая боковая панель с запоминанием состояния;
- адаптивный интерфейс для телефонов: навигация над содержимым, компактный поиск и окна лекций без горизонтальной прокрутки;
- автоматическое обновление библиотеки после загрузки и при входе с другого устройства; одинаковые названия лекций получают суффиксы `(2)`, `(3)` и далее;
- локальный плеер Plyr для обработанных видео;
- аудиодорожка извлекается через FFmpeg;
- транскрибация `stt-ru` и GigaAM-v3 с пунктуацией и таймкодами сегментов;
- русский язык интерфейса включён по умолчанию; выбранный пользователем язык интерфейса запоминается отдельно от языка лекции: русский, английский, китайский, немецкий, испанский или итальянский;
- язык видео по умолчанию определяется автоматически; русский распознаётся GigaAM-v3, английский, китайский, немецкий, испанский и итальянский — мультиязычной моделью `faster-whisper` на CPU (int8). Язык можно выбрать вручную; модель загружается при первой обработке;
- семантический поиск по нескольким лекциям на `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (FastEmbed/ONNX);
- перевод субтитров на русский, английский, китайский, немецкий, испанский или итальянский с сохранением таймкодов;
- встроенный плеер, переход к таймкоду и синхронная подсветка текущего фрагмента;
- краткий пересказ по содержанию речи, тематические главы и ключевые термины;
- повторная обработка сохранённого видео, включая ранее готовые лекции, с новым распознаванием и пересказом;
- отдельная учётная запись и собственная библиотека для каждого пользователя;
- очередь задач с этапами и процентом обработки, примерным временем, прогрессом передачи файла и скачивания по ссылке;
- видео шифруются AES-GCM, а названия, источники, конспекты, транскрипты и векторы шифруются перед записью в SQLite;
- пароли хранятся в виде стойких хешей, вход работает через защищённую cookie-сессию;
- временные расшифрованные файлы удаляются после обработки или перед запуском приложения;
- резюме и поиск выполняются локально: транскрипты не отправляются во внешнюю LLM.

## Локальный запуск без Docker

Установите Python 3.11+, FFmpeg с `ffprobe`, зависимости из `requirements.txt`, задайте `APP_USER` и `APP_PASSWORD`, затем запустите:

```sh
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## API

- `GET /api/health` — проверка доступности;
- `GET /api/lectures` — библиотека лекций;
- `POST /api/lectures/upload` — multipart-загрузка файла и названия;
- `POST /api/lectures/link` — JSON `{ "url": "https://…", "title": "…" }`;
- `GET /api/search?q=…` — семантический поиск;
- `GET /api/lectures/{id}` — статус, конспект и главы;
- `GET /api/lectures/{id}/segments` — транскрипт с таймкодами;
- `DELETE /api/lectures/{id}` — удалить лекцию и её видео.

Для русских лекций краткий конспект строится из опорных предложений по всей лекции. Для остальных выбранных языков формируются одноязычные выдержки из расшифровки и тематические главы без перефразирования; тексты остаются на языке речи. Поиск использует мультиязычный семантический индекс.

## Развёрнутый экземпляр

Прототип развёрнут на [https://demoground.ru](https://demoground.ru). На сервере служба `lectorium.service` запускает приложение из `/opt/lectorium`; база и файлы хранятся в `/var/lib/lectorium/`.

В развёрнутой версии пользователи входят в отдельные кабинеты; каждая библиотека фильтруется по владельцу. Первичный кабинет создаётся из `APP_USER`/`APP_PASSWORD` в `/etc/lectorium.env`; последующие пользователи могут зарегистрироваться самостоятельно.

Для ссылок VK Видео и Rutube используется актуальный `yt-dlp`; поддержка публичных видео зависит от доступности конкретного ролика и настроек приватности. Список поддерживаемых источников ведёт проект yt-dlp: https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md.

## Соцсети и прокси YouTube

В панели администратора откройте **Настройки**. Параметры OAuth и прокси сохраняются в базе с шифрованием приложения.

Для OAuth создайте приложения у провайдера и укажите callback-адреса:

- Яндекс: `https://demoground.ru/api/oauth/yandex/callback`
- GitHub: `https://demoground.ru/api/oauth/github/callback`
- Mail.ru: `https://demoground.ru/api/oauth/mailru/callback`

Вход через соцсеть доступен для аккаунтов, с которыми провайдер уже связан. Новая привязка из личного кабинета не предлагается.

Восстановление через электронную почту отключено. Пользователь меняет пароль в личном кабинете; администратор может задать новый пароль при утрате доступа.

Для YouTube укажите адрес HTTP- или SOCKS5-прокси и нажмите **Проверить прокси**. Если адрес в настройках пуст, приложение использует `YTDLP_PROXY` из окружения. Прокси применяется только к ссылкам YouTube.

## Поиск и помощник по материалам

Поиск работает на русском, английском, китайском, немецком, испанском и итальянском. Он объединяет многоязычные смысловые векторы исходной расшифровки с совпадениями в сохранённых переводах субтитров, пересказах и главах. Новые сохранённые переводы участвуют в следующем запросе без переиндексации. Устаревшие версии переводов не подмешиваются к изменённой расшифровке.

Поддерживаются опечатки, перестановка букв, русская транслитерация (`filosofiya`, `prostranstvo`) и неверная раскладка (`abkjcjabz`). Исправление проверяется по словарю доступных пользователю материалов. Смысловой поиск работает и для запроса на языке, на который субтитры ещё не сохранены; точные совпадения по переведённым словам появляются после сохранения соответствующего перевода.

Блок «Спросите по лекциям» позволяет выбрать все материалы, курс (папку) или отдельную готовую лекцию. Помощник использует локальную модель, учитывает последние реплики и прикладывает источники с переходом к моменту видео. Пересказ обозначается как источник и открывается с начала лекции. Если модель занята, недоступна или не вернула ответ, подтверждённый найденными фрагментами, интерфейс явно показывает выдержки из материалов вместо сгенерированного ответа. Модель может ошибаться: ссылки предназначены для проверки ответа. При отсутствии подходящих материалов помощник сообщает об этом.

История разговора хранится только в открытой вкладке, очищается при смене области поиска, языка и аккаунта. Сервер ограничивает поиск материалами текущего пользователя независимо от переданного идентификатора лекции или папки. Локальная модель ничего не отправляет внешнему ИИ-сервису. Автономное демо не запускает серверную модель и не заменяет полноценный сайт.

Проверка: `python -m unittest discover -s tests -v`, `node --check app/static/app.js`, `git diff --check`. Интеграционные тесты используют временную базу и временный ключ, включая проверки чужих лекций, отсутствия входа, устаревших переводов и недоступности модели.

## Обновление от 28 октября 2026 года: просмотр, перевод и конспекты

- Пересказ, главы и ключевые слова переводятся локальной моделью Qwen2.5-1.5B на выбранный язык интерфейса (если модель установлена; иначе используется основная модель 0.5B). Китайские заголовки разделов распознаются отдельно от основного текста; перевод сохраняется для следующих открытий.
- Обработка ускорена: реже запускается распознавание коротких аудиофрагментов, уменьшен beam size, а заголовки всех глав формируются одним запросом к локальной модели. Фактическое время зависит от длины видео и загрузки CPU.
- Для новых лекций создаётся защищённое превью из кадра исходного видео. Файл сохраняется в зашифрованном виде и выдаётся только владельцу лекции.
- Закладка с заметкой ставится кнопкой «Закладка» или клавишей `B`; все моменты собраны в отдельном разделе. Главная показывает список «Продолжить просмотр» с последней позицией.
- «Поделиться моментом» копирует или передаёт ссылку на выбранную секунду видео. В меню экспорта конспект можно скачать как Markdown или отправить на печать; в диалоге печати доступен экспорт в PDF.
- Новые таблицы закладок и прогресса добавляются при запуске приложения. Доступ ограничен владельцем лекции; заметки хранятся зашифрованными.

Автономная демонстрация остаётся заранее подготовленным примером. Новые функции требуют основного сайта и входа в аккаунт.
